03 / GOOD TO KNOW

Before you jump in.

Does CraftNode host my server for me?

No. Your server runs on your computer and uses its resources. CraftNode is the desktop interface for managing it. You supply Java and internet connectivity. Optional public setup handles a scoped firewall rule and temporary forwarding on supported UPnP routers; it cannot bypass carrier-grade NAT or ISP restrictions.

What should I know before making a server public?

Players can see your public IP, and an exposed server can attract scanning, exploits, griefing, or denial-of-service attacks. Use trusted software, backups, and a whitelist. CraftNode keeps account authentication on and disables RCON/query during setup. Stopping closes its router mapping; use Remove setup to remove the retained firewall rule with Windows permission. External reachability is not verified.

How do update notifications work?

While CraftNode is open or in the tray, version 0.2.0 checks official GitHub releases at startup and every six hours. You can also check manually or disable automatic checks in settings. Version 0.1.0 users must install this update manually once. A published release with an installer triggers alerts; a code push alone does not.

Can I bring an existing server?

Yes. Stop the original server and use Import. CraftNode copies its folder into isolated local storage, leaving the source in place. Servers requiring special launch scripts may need adaptation.

Is this an official Minecraft application?

No. CraftNode is independent software. It is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.

What happens to my worlds when I uninstall?

Uninstalling the application preserves local server data and settings. Reinstalling can find that workspace again. Open local storage in CraftNode’s settings if you want to manage retained files.
