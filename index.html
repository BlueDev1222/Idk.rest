03 / GOOD TO KNOW

Before you jump in.

Does CraftNode host my server for me?

No. Your server runs on your computer and uses its resources. CraftNode is the desktop interface for managing it. You supply the game runtime and internet connectivity. Minecraft’s optional public setup handles a scoped firewall rule and temporary forwarding on supported UPnP routers; it cannot bypass carrier-grade NAT or ISP restrictions.

What should I know before making a server public?

Players can see your public IP, and an exposed server can attract scanning, exploits, griefing, or denial-of-service attacks. Use trusted software, backups, and a whitelist. CraftNode keeps account authentication on and disables RCON/query during setup. Stopping closes its router mapping; use Remove setup to remove the retained firewall rule with Windows permission. External reachability is not verified.

How do update notifications work?

While CraftNode is open or in the tray, version 0.3.0 checks official GitHub releases at startup and every six hours. You can also check manually or disable automatic checks in settings. Version 0.1.0 users must install this update manually once. A published release with an installer triggers alerts; a code push alone does not.

Can I bring an existing server?

Yes, for Minecraft. Stop the original server and use Import. CraftNode copies its folder into isolated local storage, leaving the source in place. Servers requiring special launch scripts may need adaptation.

What happens to my existing Minecraft nodes?

CraftNode backs up the old metadata before migrating it. Your node folders, worlds, Java choices, and settings stay in place. Migration does not reinstall server software or delete worlds.

How does memory allocation work?

The Resources page shows live PC and node usage. Minecraft supports a Java heap allocation with a configurable system reserve. Terraria manages memory dynamically. Combined allocations can trigger warnings, but CraftNode never stops a node because a memory estimate is exceeded.

Is this an official Minecraft application?

No. CraftNode is independent software. It is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.

What happens to my worlds when I uninstall?

Uninstalling the application preserves local server data and settings. Reinstalling can find that workspace again. Open local storage in CraftNode’s settings if you want to manage retained files.
